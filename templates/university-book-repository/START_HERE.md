# University Book Repository Starter

Copy the contents of this directory into the root of a new book repository. Then:

1. Complete every bracketed field in `BOOK_PROFILE.md`.
2. Adapt `AGENTS.md` to the subject, author, repository layout, and commands.
3. Choose and document the editable source format and PDF toolchain.
4. Add build and verification commands before asking Codex for a finished PDF.
5. Open the repository as a new Codex workspace.
6. Start the session with the prompt below.

> Use `$university-book-authoring`. Read `AGENTS.md`, `BOOK_PROFILE.md`, and the
> documents under `docs/`. Audit the existing material before editing and follow
> the repository's complete teaching, visual, assessment, and publication
> standards.

To confirm that Codex found the instructions, ask it to list the active
instruction files and summarize the project contract before beginning a large
revision.
