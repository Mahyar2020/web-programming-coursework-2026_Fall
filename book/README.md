# Student Book

*Web Programming: From the Platform to Production* is designed as a five-part
living reference. The checked items below are published in the current
Foundations Edition. Unchecked items define the reviewed production sequence and
will not be represented as finished chapters until their prose, lab, complete
answers, quiz explanations, figures, code tests, and PDF layout all pass the
chapter release contract.

## Before Part I

0. [x] [Prepare Your Web-Programming Workstation](part-0-orientation/00-development-environment-setup.md)

Complete this zero-start orientation before Session 1. It explains the required
equipment and accounts, installs the browser, developer tools, code editor, Git,
Node.js, and npm on Windows, macOS, or Linux, and ends with a recorded readiness
check. Experienced students may verify an existing workstation instead of
reinstalling software.

## Part V - Advanced Web Systems

Chapters 16–27 cover browser performance, real-time communication, GraphQL,
server rendering, advanced PostgreSQL, distributed systems,
internationalization, progressive web applications, privacy, software supply
chains, WebAssembly, and vendor-neutral cloud architecture. See the
[complete book architecture](../docs/BOOK_ARCHITECTURE.md) for the approved
chapter descriptions and dependencies.

Each chapter includes learning outcomes, explanations, a guided laboratory,
exercises, complete worked answers, a quiz with explanations, a summary, and
primary references..
